# Testing the New QR Code Feedback API via Postman

Now that we have integrated the new Feedback endpoints, here is a step-by-step guide to testing them using Postman.

## Pre-requisites
1. Ensure your backend server is running (`npm run dev` or `npm start` in your `backend` directory).
2. Ensure you have an existing **Batch ID**. You can get a valid Batch ID by querying your local MongoDB or by checking your `ProductBatch` collection.

*Note: For these examples, replace `<YOUR_BATCH_ID>` with an actual 24-character MongoDB ObjectId from your `products` or `batches` collection, for example: `65a1234567890abcdef12345`*

---

## 1. Test: Submit Feedback (POST)

We will simulate a consumer submitting a rating and comment for a specific product batch.

* **Method:** `POST`
* **URL:** `http://localhost:5000/api/consumer/feedback/<YOUR_BATCH_ID>` (Adjust your port if your server runs on a different one, usually 5000 or 8000)
* **Headers:**
  * `Content-Type`: `application/json`
  * *(Optional if route is protected with JWT token)* `Authorization`: `Bearer <YOUR_CONSUMER_JWT_TOKEN>`
* **Body (Raw JSON):**
```json
{
    "rating": 5,
    "comment": "This organic produce was incredibly fresh! Highly recommended."
}
```

**Expected Result:** You should get a `201 Created` status with `success: true` and the saved feedback object.

---

## 2. Test: Get Feedback for a Batch (GET)

Now we will fetch the review we just posted.

* **Method:** `GET`
* **URL:** `http://localhost:5000/api/consumer/feedback/<YOUR_BATCH_ID>`

**Expected Result:** You should get a `200 OK` status with `success: true`. The `data` should contain the `averageRating`, `totalReviews`, and an array of individual `reviews`.

---

## 3. Test: Generate 3rd Party QR Code (GET)

This endpoint calls `api.qrserver.com` to generate a link to a QR code image that. When scanned by a phone, the QR code redirects the consumer to a dummy feedback page on your site.

* **Method:** `GET`
* **URL:** `http://localhost:5000/api/consumer/qrcode-feedback/<YOUR_BATCH_ID>`

**Expected Result:** You should get a `200 OK` response resembling:
```json
{
    "success": true,
    "data": {
        "batchId": "<YOUR_BATCH_ID>",
        "feedbackUrl": "http://localhost:5000/feedback/<YOUR_BATCH_ID>",
        "qrCodeUrl": "https://api.qrserver.com/v1/create-qr-code/?data=http%3A%2F%2Flocalhost%3A5000%2Ffeedback%2F<YOUR_BATCH_ID>&size=250x250&format=png&margin=10"
    }
}
```

* **To see the QR Code:** Copy the `qrCodeUrl` from the response and paste it directly into your web browser! You will see the QR code generated by the third-party API.

---

### Troubleshooting
* **"Product not found" (404 Error):** The Batch ID you put in the URL doesn't exist in your database. Ensure you use an ID that matches a real `ProductBatch`.
* **"Rating must be between 1 and 5" (400 Error):** You sent a rating of 0, 6, or didn't include it in your POST body.
